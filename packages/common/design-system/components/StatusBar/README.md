# StatusBar
Optional bottom bar after the game's chat bar: platform and version at the left, a short status in the middle (last import), the clock at the right. Raised film, hairline above.
Use it only on the desktop shell; on the web it is usually off and the version lives under the settings menu. Never put navigation in it.
**Consumer provides:** version string, status text, whether to show a clock. **Material:** none.
