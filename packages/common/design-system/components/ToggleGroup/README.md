# ToggleGroup
A row of small square toggles for views and filters (the game's list / folder icons above the replay list). One pressed at a time (`aria-pressed`), or several for filters. Pressed: selection fill, strong border, selected glow.
**Material:** `mat-button-toggle-group` with shape 0 and `--mat-button-toggle-selected-state-background-color: var(--hrs-selection)`.
