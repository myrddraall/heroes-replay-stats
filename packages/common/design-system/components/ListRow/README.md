# ListRow
A slot row after the game's lobby: a leading square slot (portrait or team mark), the name, trailing actions. Film with a half-strength hairline so a stack of rows reads as one block; `--empty` for open slots in hrs-text-dim.
Use for rosters, import queues and anything that is "a list of slots" rather than a table. Selected: selection fill, strong border.
**Consumer provides:** slot content, label, trailing controls.
