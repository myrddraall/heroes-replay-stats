# ProgressBar
A thin bordered track with an hrs-accent fill and glow. `--gold` for XP/level style bars, `--xp` for the taller segmented bar after the score screen. Determinate only; a running job with no total shows the UtilityPod's bottom bar sweeping.
**Material:** `mat-progress-bar` with `--mat-progress-bar-active-indicator-color: var(--hrs-accent)`, track hrs-border, height 8px, shape 0.
