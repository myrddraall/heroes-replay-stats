# SelectionList
A vertical stack of full-width bordered buttons where one (or none) is current: categories, presets, saved views. The same look as SideNav items, usable inside any Panel or Drawer.
- Items: film, hairline, `nav-3`. Current: selection fill, strong border, selected glow. Hover: strong border, hover glow.
- A trailing count or icon sits at the right end.
**Consumer provides:** items, the current one. Use Tabs instead when the choices are few and horizontal space is there.
