# Badge
A small count: bold digits on a raised fill with a strong border, radius hrs-radius-1. Built around 1em (0.72em of its parent by default), so it follows the text it sits in. `--filled` inverts to hrs-accent with hrs-on-accent text. `--corner` pins it to the top-left corner of a pod or button, after the game's "+" on currency pods.
Counts only; words go in a Chip.
**Material:** `matBadge` is not used (its position and shape differ); this class instead.
