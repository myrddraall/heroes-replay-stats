# Slider
A 6px bordered track with the filled part in hrs-accent, a 12×18 square handle in hrs-text with a strong border and glow, and the value in `numeric` at the right. For continuous settings (surface opacity, scene brightness).
**Material:** `mat-slider` via `mat.slider-overrides`: active track hrs-accent, inactive hrs-border, handle hrs-text, shape 0, value indicator off (the output shows it).
