# UtilityPod
A bordered value pill in the TopBar's utility cluster, after the game's currency pods: icon, a tabular number or short label, and an optional corner badge with "+" for the action it offers (import more).
- Rest: film and hairline. With a job running: a 2px progress bar along the bottom edge in hrs-accent.
- Clicking opens the Popover for that thing (import queue) or routes to its page.
**Consumer provides:** icon, value, optional progress 0–1, the action. **Material:** a `mat-button` with the pod classes, or a plain button.
