# Tabs
In-page tabs with the SubBar look (`nav-2`, dividers, glow underline on the selected tab), for switching views inside a Panel (About / Skins / Abilities / Talents). Selected tab: `aria-selected="true"`.
The level-2 SubBar is the same component placed in the shell; keep in-page tabs to one row per panel.
**Material:** `mat-tab-group` through `mat.tabs-overrides`: indicator hrs-accent 2px, divider hrs-border, label `nav-2`, no ripple.
