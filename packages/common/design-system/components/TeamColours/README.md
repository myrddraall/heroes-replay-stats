# TeamColours
The semantic colours in use: ally names in hrs-team-blue, enemy names in hrs-team-red, the user's own player in hrs-self wherever they appear, hrs-gold for ownership and MVP, hrs-error / hrs-info / hrs-warning for chat-style lines. They do not change with the theme.
Whole-team panels take the team theme (`theme="blue"` / `"red"`) and keep the name colours inside; the user's row inside a team panel is still hrs-self. Which team is blue follows the app's perspective setting (relative: your team; fixed: team 1).
