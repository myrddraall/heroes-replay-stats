# Rarity
The six rarity themes: `theme="poor|common|uncommon|rare|epic|legendary"` (grey, white, green, blue, purple, orange: the WoW item-quality hues). They are full themes with the same roles as purple, cyan, blue, red and green: an item card, a chip, a name or a whole panel carrying one takes that tier's films, borders, accent and glow. The glow strength climbs with the tier (`--hrs-glow-k`: poor 0.35 → legendary 1.15), so a legendary item lights up and a poor one barely does; poor and common have no chroma at all.
Each coloured tier sits on its WoW item-quality colour (uncommon #1eff00, rare #0070dd, epic #a335ee, legendary #ff8000) and is more saturated than the base themes, so it differs from its neighbour by saturation as well as hue: epic (306, vivid orchid) beside purple (286, soft violet), rare (250, deep azure) beside blue team (266, pale periwinkle), uncommon (142, vivid yellow-green) beside green (158, softer emerald).
