# ThemeVariants
Twelve themes, one mechanism: a `theme` attribute on any element re-tints everything inside it. Six base themes (tokens.css declares them per theme on `[theme]`): the shell carries the neutral one (purple, or magenta or cyan when the user picks it); a team panel carries `blue` or `red`; a panel about the user carries `green`. Six rarity themes (bundle.css declares them from the same role table): `poor`, `common`, `uncommon`, `rare`, `epic`, `legendary` for items, loot and talent tiers. Nesting is free: a red roster inside a purple page, an epic card inside a blue panel.
Each row shows the theme on the nav bars (the game's textures, recoloured), a panel with buttons and muted text, a StyledText glow and an item frame.
Rule: a theme changes surfaces, borders, accents and glows; it never changes the semantic colours (team-blue, team-red, self, gold, error, info), which stay the same in every theme.
